# Contributing Guidelines

## Pull Request Rules
1. **Visual Proof Requirement**: Any pull request that modifies HTML, CSS, layouts, components, or client-side assets MUST include screenshots or screen recordings in the PR description demonstrating the rendered output.
2. **Reviewers & Assignees**: Ensure the relevant assignees and reviewers are added to PRs.
3. **Clean Commits**: Write clear, imperative commit messages (`feat: ...`, `fix: ...`).
